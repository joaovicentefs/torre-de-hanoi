# Torre de Hanói

PWA offline da Torre de Hanói: jornada de 30 fases, Expedição com fases procedurais, desafio diário, modo livre, temas e conquistas.

Jogar: https://joaovicentefs.github.io/torre-de-hanoi/

No iPhone: abra no Safari, toque em Compartilhar e em Adicionar à Tela de Início. Depois da primeira abertura, funciona sem internet.

Para publicar uma versão nova, troque `hanoi-v1` em `sw.js` pelo próximo número.
